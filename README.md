# Sloth 法漢詞典 — web demo

Static demo for the open, redistributable French → Traditional Chinese Kobo dictionary.

Live: https://vieenrose.github.io/sloth-fr-zh-demo/

The demo is generated from the private `vieenrose/sloth-fr-zh-dict-for-kobo`
repository (`open` branch, `docs/` folder). `demo-version.json` shows the source
commit SHA. Dictionary data and build scripts are in that repository.
